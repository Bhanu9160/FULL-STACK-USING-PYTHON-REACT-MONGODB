# Full Stack Development

## Module 1 - Day 6

### Topic

Functions in Python

### Objective

Learn how to create reusable blocks of code using functions. Functions help reduce code duplication, improve readability, and make programs modular.

### Topics Covered

- Introduction to Functions
- Creating Functions
- Calling Functions
- Parameters
- Arguments
- Return Statement
- Built-in Functions
- User-defined Functions
- Local Variables
- Global Variables

### Tools Used

- Python 3
- VS Code

### Mini Project

Simple Banking System

### Learning Outcome

- Understand the purpose of functions.
- Create and call user-defined functions.
- Use parameters and arguments.
- Return values using the return statement.
- Differentiate between local and global variables.
- Build a menu-driven banking application.
