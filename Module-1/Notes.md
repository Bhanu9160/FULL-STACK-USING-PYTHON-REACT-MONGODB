# Module 1 - Day 1 Notes

## 1. What is Python?

### What is it?
Python is a high-level, interpreted, object-oriented programming language used for web development, automation, artificial intelligence, data science, cybersecurity, and software development.

### Why do we use it?
- Easy to learn and understand.
- Simple syntax.
- Cross-platform.
- Open source.
- Large standard library.
- Widely used for backend development.

---

## 2. Features of Python

### What is it?
Python provides many features that make programming easier and more efficient.

### Features
- Easy to Learn
- Easy to Read
- Interpreted Language
- Object-Oriented
- Cross-Platform
- Open Source
- Large Standard Library

---

## 3. Installing Python

### What is it?
Installing Python allows us to write and execute Python programs.

### Why do we use it?
Without Python, we cannot run Python programs.

---

## 4. First Python Program

### What is it?
The first program is used to verify that Python is installed correctly.

### Program

print("Hello, World!")

### How does it work?
- print() is a built-in Python function.
- "Hello, World!" is a string.
- Python prints the string on the screen.

---

## 5. Variables

### What is it?
A variable is a named memory location used to store data.

### Why do we use it?
Variables help us store and reuse information.

### Example

name = "Bhanu"
age = 21
cgpa = 8.3

---

## 6. Data Types

### Integer (int)
Stores whole numbers.

Example

age = 21

### Float (float)
Stores decimal numbers.

Example

cgpa = 8.3

### String (str)
Stores text.

Example

name = "Bhanu"

### Boolean (bool)
Stores True or False.

Example

is_student = True

---

## 7. Print Function

### What is it?
The print() function displays output on the screen.

### Example

print(name)

---

## 8. Comments

### What is it?
Comments are notes written in the program to explain the code. Python ignores comments during execution.

### Single-Line Comment

# This is a comment

### Multi-Line Comment

"""
This is a
multi-line comment.
"""
