# Student Information Portal using Flask

## Project Overview
This is a beginner Flask web application created to understand the basics of Flask routing. The project contains multiple web pages such as Home, Student Details, Skills, Projects, and Contact.

## Features
- Home Page
- Student Details Page
- Skills Page
- Projects Page
- Contact Page

## Technologies Used
- Python 3
- Flask

## Project Structure

Student_Portal/
│── app.py
│── README.md

## How to Run

1. Install Flask

pip install flask

2. Run the application

python app.py

3. Open your browser

http://127.0.0.1:5000/

## Learning Outcomes
- Importing Flask
- Creating a Flask application
- Using @app.route()
- Running a local web server
- Creating multiple routes
