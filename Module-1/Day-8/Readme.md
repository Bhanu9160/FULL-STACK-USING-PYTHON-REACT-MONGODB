# Module 4 - Day 2
# Flask Routing

## 📖 Overview

This project demonstrates the basics of **Routing in Flask**. It includes static routes, dynamic routes, URL parameters, integer parameters, and multiple parameters.

---

## 🎯 Objectives

- Learn Flask Routing
- Create Static Routes
- Create Dynamic Routes
- Pass Parameters through URLs
- Work with Integer URL Parameters
- Build a simple Student Result Portal

---

## 🛠 Technologies Used

- Python 3
- Flask

## ▶️ How to Run

### Install Flask

```bash
pip install flask
```

### Run the Application

```bash
py app.py
```

or

```bash
python app.py
```
