# Full Stack Development

## Module 1 - Day 3

### Topic
Strings & Conditional Statements

### Objective
Learn how to work with strings and make decisions using conditional statements in Python. These concepts are fundamental for processing user input, validating data, and implementing application logic.

### Topics Covered

- Introduction to Strings
- Creating Strings
- String Indexing
- String Slicing
- String Methods
- String Formatting
- Conditional Statements
- if Statement
- if...else Statement
- if...elif...else Statement
- Nested if Statement

### Tools Used

- Python 3
- VS Code

### Mini Project

Student Information & Grade Analyzer

### Learning Outcome

- Understand string operations.
- Learn commonly used string methods.
- Implement decision-making using conditional statements.
- Build a real-world Python application.
