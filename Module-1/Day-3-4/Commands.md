# Module 1 - Day 3 Commands

## String Length

```python
len(string)
```

---

## String Indexing

```python
string[index]
```

---

## String Slicing

```python
string[start:end]
```

---

## Convert to Uppercase

```python
string.upper()
```

---

## Convert to Lowercase

```python
string.lower()
```

---

## Convert to Title Case

```python
string.title()
```

---

## Remove Spaces

```python
string.strip()
```

---

## Replace Text

```python
string.replace(old, new)
```

---

## Split String

```python
string.split()
```

---

## String Formatting

```python
f"{variable}"
```

---

## if Statement

```python
if condition:
    statement
```

---

## if...else Statement

```python
if condition:
    statement
else:
    statement
```

---

## if...elif...else Statement

```python
if condition:
    statement
elif condition:
    statement
else:
    statement
```

---

## Nested if Statement

```python
if condition:
    if condition:
        statement
```
