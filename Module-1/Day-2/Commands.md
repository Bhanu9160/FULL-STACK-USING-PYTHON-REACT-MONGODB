# Module 1 - Day 2 Commands

## Check Python Version

```bash
python --version
```

or

```bash
python3 --version
```

---

## Start Python Interpreter

```bash
python
```

or

```bash
python3
```

---

## Run a Python Program

```bash
python filename.py
```

or

```bash
python3 filename.py
```

---

## Exit Python Interpreter

```python
exit()
```

or

```python
quit()
```

---

## Take String Input

```python
name = input("Enter your name: ")
```

---

## Take Integer Input

```python
age = int(input("Enter your age: "))
```

---

## Take Float Input

```python
cgpa = float(input("Enter your CGPA: ")
```

---
