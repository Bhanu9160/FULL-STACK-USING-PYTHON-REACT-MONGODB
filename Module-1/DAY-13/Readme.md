# Flask Student Form App

A simple Flask web application that displays a homepage with the current timestamp and accepts a form submission (username, email, roll number) to display the submitted details on an output page.

## Features

- Displays the current date and time on the homepage
- Accepts user input via a form (username, email, roll number)
- Displays submitted form data on a separate output page

- Flask
