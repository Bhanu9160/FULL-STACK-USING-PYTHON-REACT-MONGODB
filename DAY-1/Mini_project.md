# Module 1 - Day 1 Mini Project

## Project Name
Student Information System

## Objective
Create a Python program that stores and displays student information using variables and the `print()` function.

## Requirements

Store the following details in variables:
- Name
- Age
- College
- Branch
- CGPA

Display all the information using the `print()` function.

## Example Code

```python
name = "Bhanu"
age = 21
college = "VVIT"
branch = "Cyber Security"
cgpa = 8.3

print("Name :", name)
print("Age :", age)
print("College :", college)
print("Branch :", branch)
print("CGPA :", cgpa)
```

## Expected Output

```text
Name : Bhanu
Age : 21
College : VVIT
Branch : Cyber Security
CGPA : 8.3
```

## Learning Outcome

- Learned how to create variables.
- Understood Python data types.
- Practiced using the `print()` function.
- Learned how to display formatted output.
